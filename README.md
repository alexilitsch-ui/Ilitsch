# 🔮 Оракул — бот Таро и гороскопов с ИИ

Человек вводит **имя** и **дату рождения**, а бот:

- определяет знак зодиака, стихию, планету, восточный гороскоп и число жизненного пути;
- составляет **персональный гороскоп на сегодня**;
- делает расклады Таро (полная колода, 78 карт): **карта дня**, **прошлое — настоящее — будущее**, **любовный расклад**, **ответ на вопрос**;
- позволяет **свободно поговорить с Оракулом** (чат с ИИ, который помнит разговор).

Толкования пишет ИИ **Claude** (Anthropic). Без ключа бот тоже работает, но в простом режиме — по встроенным значениям карт.

Работает двумя способами:
1. **На компьютере в консоли** — `python main.py`
2. **Как Telegram-бот**, запущенный на вашем компьютере — `python main.py telegram`

## Как подключить ИИ к компьютеру

### 1. Установите Python
Скачайте Python 3.10 или новее с https://www.python.org/downloads/
(на Windows при установке поставьте галочку **Add Python to PATH**).

### 2. Скачайте проект
```
git clone https://github.com/alexilitsch-ui/Ilitsch.git
cd Ilitsch
```

### 3. Получите ключ ИИ
1. Зарегистрируйтесь на https://console.anthropic.com
2. Пополните баланс (оплата за использование, одно предсказание стоит доли цента — несколько центов).
3. В разделе **API Keys** создайте ключ — он начинается с `sk-ant-`.

### 4. Впишите ключ
Скопируйте файл `.env.example` в `.env` и вставьте ключ:
```
ANTHROPIC_API_KEY=sk-ant-ваш-ключ
```
Файл `.env` не попадает в git — ключ останется только у вас на компьютере.

### 5. Запустите
- **Windows:** дважды щёлкните `start.bat`
- **macOS / Linux:** `./start.sh`

При первом запуске скрипт сам создаст окружение и установит зависимости.

Вручную то же самое:
```
pip install -r requirements.txt
python main.py
```

## Telegram-бот

1. В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Добавьте его в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   ```
3. Запустите: `start.bat telegram` (Windows) или `./start.sh telegram`.
4. Откройте своего бота в Telegram и отправьте `/start`.

Бот работает, пока программа запущена на компьютере.

## Настройки (`.env`)

| Переменная | Что это | По умолчанию |
|---|---|---|
| `ANTHROPIC_API_KEY` | ключ ИИ Claude | — (без него простой режим) |
| `TELEGRAM_BOT_TOKEN` | токен Telegram-бота | — |
| `ORACLE_MODEL` | модель ИИ | `claude-opus-5-5` |
| `ORACLE_EFFORT` | глубина размышлений: `low`, `medium`, `high` | `medium` |

```
oracle/cli.py         — консольное меню
oracle/telegram_bot.py — Telegram-бот
tests/                — тесты (pytest)
```
